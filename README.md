# Простор

Статический сайт на Astro с TypeScript. Главная страница перенесена из экспорта Claude Design и собрана из секционных компонентов в `src/components/home/`.

## Локальная работа

Требуется Node.js 22.23.4 или новее.

```sh
npm install
npm run dev
```

Проверка типов Astro и сборка статического сайта:

```sh
npm run check
npm run build
npm run preview
```

Сборка размещается в `dist/`. Шрифты и используемые изображения хранятся локально в `public/`; сайт не загружает ресурсы с внешних CDN.

## Структура

- `src/pages/` — маршруты сайта.
- `src/layouts/` — общая HTML-оболочка и SEO-метаданные.
- `src/components/home/` — секции главной страницы.
- `src/scripts/` — небольшая клиентская логика на TypeScript.
- `src/styles/` — общие стили и дизайн-правила.
- `public/` — локальные изображения, шрифты и runtime `<image-slot>`.
- `reference-claude-design.html` — исходный HTML-экспорт для сверки.
- `src/cases/`, `src/team/`, `src/chips/` — исходные изображения.

Кейсы, статьи, типовые страницы и SEO-данные можно добавлять отдельным этапом после утверждения главной.
